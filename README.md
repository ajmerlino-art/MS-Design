# MS Design for Business Innovation Dashboard

Public GitHub Pages dashboard files for the WGU MS Design for Business Innovation program concept.

## Primary files
- `ms_dbi_dashboard.html` (interactive dashboard)
- `data/ms_dbi_program_data.json` (source data)
- `ms_dbi_skills_library.csv`
- `ms_dbi_course_layout_tasks.csv`
- `ms_dbi_competitive_analysis.csv`

## Regenerate
Run:

```bash
ruby scripts/render_ms_dbi_dashboard.rb
```
